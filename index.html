Import data

Supported CSV format: one row per date and columns named below. Header names are case-insensitive. Imports replace entries on matching dates; Hevy imports merge sets.

Apple Health exports usually contain a large XML archive, not the CSV formats above. Direct HealthKit access is not available to this web app. A future iOS Shortcut or native companion will be needed for automatic transfer.

Your data and backups

The dashboard has no account, trackers, or servers. Photos stay in this browser; JSON backup includes entered metrics and workout sets, not photo files. Export photo originals separately. Clearing Safari website data can erase local records.

Install to iPhone home screen

Host these files over HTTPS (for example, free GitHub Pages). On iPhone: open the URL in Safari → Share → Add to Home Screen → Add. Save a backup periodically. Opening index.html as a local file is not an equivalent permanent installation.
